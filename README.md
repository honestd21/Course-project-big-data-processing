# Описание предметной области и исходных данных

**Дисциплина:** Б1.В.14 «Большие данные в сельском хозяйстве», курсовой проект
**Направление курсового проекта:** «Качество и предобработка данных, подходы и инструменты»

**Предлагаемая тема:** Оценка качества данных и автоматизация их проверки в задаче прогнозирования урожайности сельскохозяйственных культур и влияние дефектов данных на качество моделей машинного обучения

**Исходный набор данных:** Kaggle, `patelris/crop-yield-prediction-dataset` (итоговая таблица `yield_df.csv` и пять исходных файлов, из которых она собрана)

---

## 1. Предметная область

Прогнозирование урожайности сельскохозяйственных культур по климатическим и агротехническим факторам.

- **Прикладная задача:** оценить урожайность культуры (регрессия) для страны и года по осадкам, температуре и использованию пестицидов.
- **Значимость:** планирование производства и поставок, оценка продовольственной безопасности, анализ влияния климата на урожайность.
- **Тип данных:** табличные панельные данные (страна × культура × год).
- **Источники:** статистика FAO (файлы урожайности и пестицидов имеют структуру выгрузок FAOSTAT), климатические данные по странам.
- **Проблема качества данных:** международная статистика собирается из нескольких источников. При объединении возникают дубликаты, конфликты значений, пропуски и расхождения форматов. От этого зависят метрики модели и достоверность выводов.

## 3. Результаты предварительного анализа качества данных

Скрытые дефекты, обнаруженные при профилировании файлов:

| № | Дефект | Количественная оценка |
|---|--------|----------------------|
| 1 | **Размножение строк при объединении.** В `temp.csv` ключи (страна, год) повторяются с разными значениями температуры. После объединения одна и та же запись об урожайности встречается дважды с разной температурой | 18 949 строк (67,1 %) делят ключ (`Area`, `Item`, `Year`). Уникальных ключей 13 130, лишних строк 15 112. Для 3 690 ключей температура различается (медианный разрыв около 4,2 °C), урожайность во всех таких случаях одинакова |
| 2 | **Дефекты исходного файла температуры** | 6 958 полностью повторяющихся строк, 7 534 пары (страна, год) с конфликтующими значениями, 2 547 пропусков |
| 3 | **«Осадки» не меняются по годам.** Значение является константой страны, а не годовой характеристикой | В итоговой таблице у всех 101 страны одно значение за все годы. В исходном файле у 188 из 217 стран одно значение, у 25 значения нет, у 4 их два |
| 4 | **Дефекты исходного файла осадков** | 774 пропуска, 6 значений «..», числовой столбец прочитан как строка, в названии столбца `Area` лишний пробел |
| 5 | **Несогласованность температуры внутри страны и года** | 575 из 2 250 сочетаний (страна, год) имеют более одного значения температуры |
| 6 | **Асимметрия целевой переменной и выбросы** | Асимметрия 1,79; по правилу IQR выбросы: пшеница 8,6 %, плантаны 7,6 %, кукуруза 5,0 % |
| 7 | **Пестициды:** распределение сильно скошено | Асимметрия 3,49 |

Вывод: искусственного внесения дефектов для демонстрации проверок не требуется, реальные дефекты уже присутствуют. Дополнительно планируется контролируемая порча данных для измерения полноты обнаружения.

## 4. Почему выбран этот набор данных

- Задача из АПК, данные международной статистики FAO.
- Табличный формат среднего размера: считается быстро, без GPU, подходит для сравнения моделей.
- Данные собраны из нескольких источников, поэтому реальные дефекты (дубликаты, конфликты, пропуски, константы) уже есть и подтверждены измерениями.
- Структура «страна × год» позволяет показать разницу между завышенной и корректной оценкой качества.
- Доступны как итоговая таблица, так и исходные файлы, что даёт возможность воспроизвести сборку и найти причины дефектов.
- По набору существуют научные публикации, их можно использовать в обзоре литературы.

## 5. Цель и задачи

**Цель:** разработка прототипа системы оценки и автоматической проверки качества данных для прогнозирования урожайности сельскохозяйственных культур с использованием методов машинного обучения и Python-инструментария.

**Задачи:**
1. Изучить теоретические основы качества данных, виды дефектов и методы их обнаружения в задачах прогнозирования урожайности.
2. Выполнить профилирование исходных файлов и итоговой таблицы, описать выявленные дефекты.
3. Разработать набор автоматических правил проверки качества данных (уникальность ключа, согласованность источников, диапазоны, пропуски, константность, согласованность названий).
4. Оценить полноту обнаружения дефектов и долю ложных срабатываний на данных с контролируемо внесёнными нарушениями.
5. Обучить модели машинного обучения и сравнить метрики на данных с разным уровнем дефектов, а также до и после автоматической проверки и очистки.
6. Сравнить схемы валидации (случайная, по странам, по времени) и оценить степень завышения метрик.
7. Сформулировать выводы, ограничения и рекомендации.

## 6. Что сравниваем

| Что | Варианты |
|-----|----------|
| Схема проверки | случайное разбиение; по странам (GroupKFold); по времени |
| Состояние данных | исходные; после удаления дублей; после полной автоматической очистки |
| Уровень дефектов | контролируемые пропуски, выбросы, дубликаты 5, 10, 20, 30 % |
| Типы пропусков | MCAR, MAR, MNAR |
| Обработка пропусков | удаление строк, медиана, KNN, IterativeImputer |
| Обработка выбросов | не трогать, IQR, IsolationForest, винзоризация |
| Модели | Ridge-регрессия, Random Forest, XGBoost или LightGBM, небольшой MLP |

Вся предобработка выполняется внутри `Pipeline` только на обучающей части.

---

## 7. Метрики и протокол

- **Метрики модели:** MAE, RMSE, R².
- **Метрики проверок качества:** полнота обнаружения внесённых дефектов, доля ложных срабатываний, число нарушений правил до и после очистки.
- **Устойчивость:** несколько запусков с разными seed, среднее ± разброс.
- **Воспроизводимость:** фиксированный seed, логирование экспериментов.
- **Анализ ошибок:** по странам и культурам, график остатков, важность признаков, при наличии координат карта ошибок по странам.
